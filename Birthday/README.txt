HOW TO PERSONALIZE THIS WEBSITE
================================

1. PHOTOS
   Drop your real photos into the /images folder, named:
   photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg, photo5.jpg
   (or rename the paths in memories.html to match your own filenames)
   Edit the caption text under each photo — look for <!-- CAPTION — REPLACE THIS -->

2. VIDEOS
   Drop your videos into the /videos folder, named:
   video1.mp4, video2.mp4
   Add more by duplicating a whole <div class="video-frame">...</div> block in memories.html.

3. MUSIC (optional)
   Drop an mp3 into /audio named birthday-song.mp3.
   If you skip this, the music button will just quietly tell you to add a file — nothing breaks.

4. TEXT
   Every place you should edit is marked with a comment like:
   <!-- CAPTION — REPLACE THIS -->
   <!-- PERSONAL MESSAGE — REPLACE THIS -->
   Just search for "REPLACE" in each file to find every spot.

5. FLIP CARDS, TIMELINE, ENVELOPES, QUIZ
   Each of these is a repeatable block of HTML in memories.html, letters.html, and games.html.
   To add another one, copy an existing block (e.g. one .flip-card, one .envelope,
   one .timeline-item, one .quiz-question) and edit the text inside.
   You never need to touch script.js to add more content — it works automatically.

6. OPENING THE SITE
   Just double-click index.html to open it in your browser. No install, no server, no build step.
